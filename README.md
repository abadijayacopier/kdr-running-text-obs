# KDR Running Text OBS

Native OBS Studio plugin for customizable running text overlays.\n\n**Developer:** Supriyanto — Abadi Jaya

## V1
- Native OBS source: **KDR Running Text**
- Editable text
- Direction and speed settings
- Font size and basic styling settings
- Transparent background
- Custom canvas width/height
- Theme selector foundation
- Prepared for Windows CI packaging

## Roadmap
1. Stable native source and settings
2. Real-time text rendering and smooth scrolling
3. Logo/icon support
4. 5 built-in themes
5. Custom position, outline and shadow
6. Presets/templates
7. Windows installer

The project follows the current OBS plugin-template approach from the OBS Project. See the official template for supported build environments and CI conventions.
